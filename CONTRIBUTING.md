# Contributing to Leenq

Thank you for your interest in contributing! Contributions help make this project better and more secure. This guide explains how to contribute safely and effectively.

## How to Contribute

1. **Fork the Repository**  
   Create a copy of this project under your own GitHub account.

2. **Clone Your Fork**  
   Download it to your local machine:
   ```bash
   git clone https://github.com/your-username/leenq.git
   ```

3. **Create a New Branch**
   Make a branch for your feature or bug fix:

   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Make Changes**

   * Write clear, readable code.
   * Add comments where necessary.
   * Test your changes to make sure they work on all supported platforms.

5. **Commit Your Changes**
   Use descriptive commit messages, e.g.:

   ```bash
   git commit -m "feat: add clipboard sync for Android"
   ```

6. **Push Your Branch**

   ```bash
   git push origin feature/your-feature-name
   ```

7. **Open a Pull Request**

   * Go to the main repository and submit a pull request.
   * Describe your changes clearly and link any related issues.

---

> [!IMPORTANT]
> * Follow consistent naming conventions.
> * Keep code modular and readable.
> * Avoid large, unreviewable changes in a single commit.

## Versioning Guidelines

This project uses **semantic versioning (MAJOR.MINOR.PATCH)**:

* **MAJOR** version: incompatible changes or major new features
* **MINOR** version: backward-compatible new features
* **PATCH** version: backward-compatible bug fixes and security updates

When contributing:

* If your change fixes a bug or security issue, it will go in the **next patch release**.
* If your change adds a new feature, it may go in the **next minor release**.
* Breaking changes are reserved for **major releases**.

## Reporting Issues

* Use the **Issues** tab to report bugs or request new features.
* Include details such as:

  * Platform (Windows, Linux, macOS, Android, iOS)
  * Version of the software
  * Steps to reproduce the problem
