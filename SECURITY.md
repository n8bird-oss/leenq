# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability in this project, please report it immediately by emailing **a41622100@gmail.com**. Avoid opening public issues for security-related problems.

## Supported Versions
This project supports the latest stable version. Security fixes will be provided for active releases only.

## Security Best Practices
- Keep the software updated to the latest version.
- Only download binaries from official releases.
- Avoid running untrusted code on your system.
